# Dashboard mounted component checks

This opt-in suite mounts the real `ObservationChart`, `TargetHealthPanel`, `TargetAlertsPanel`, `TargetActivityPanel`, `TargetDeadlockPanel`, `TargetWaitsPanel`, `AnalyticsSurfacePanel`, `TargetOnboarding`, `ServersPage`, `OperationsPanel`, `ReportsPanel`, `TargetManagementPanel`, `IncidentWorkspace`, `SqlVolumePanel` and `TargetAlertRulesPanel` through dedicated harnesses, importing the product stylesheet and serving HTML/TSX entries through the existing Vite configuration and React plugin. Components that use time display mount under the real `TimeDisplayProvider`. It uses the already installed React, Vite, Playwright and axe dependencies. Harness controls change real props; tests exercise the production transport/parsers with intercepted native synthetic DTOs.

Run from `web` with existing dependencies and the existing Chromium installation:

```powershell
pnpm exec tsc --project tsconfig.component-tests.json --noEmit --pretty false
node --experimental-strip-types --test tests/health-contract.test.mjs tests/alert-contract.test.mjs tests/alert-ui-validation.test.mjs tests/activity-contract.test.mjs tests/deadlock-parser.test.mjs tests/onboarding-contract.test.mjs tests/operations-contract.test.mjs tests/reports-contract.test.mjs tests/analytics-ui-validation.test.mjs
pnpm exec playwright test --config playwright.dashboard-components.config.mjs
```

The suite starts one Vite server at `127.0.0.1:4328` with strict port ownership, then stops it when Playwright finishes. It does not run a product build, write `dist` or require a database. Chart tests reject API traffic; non-chart tests fulfill only registered API requests locally and abort/report unexpected API or external HTTP requests and browser runtime errors before the Vite proxy/backend is reached. The TypeScript configuration inherits source strict flags and checks all product TS/declarations plus TSX harnesses; browser specs and fixtures remain ES modules like the existing Playwright suites.

Eighty-three defined behavioral tests cover chart evidence/inspection; collector loss/completeness, exact file counters, database paging, inert names, safe failures and late server requests; and permission/state-gated acknowledgement, stable retries with bodyless 204, filtered/missing selections, pending paging and context-change cancellation. Chart, Health, Activity, Deadlock, Analytics, Onboarding and Operations responsive cases check axe, focus and overflow at 320/1440 pixels. Reports checks readable shared time controls/window summaries, export hit sizes, axe, focus and overflow at 320/390/768/1440. Gap checks use browser-computed stroke bounds/length, without reproducing SVG path strings or model calculations. Pointer cancellation uses a browser event because Playwright's mouse API has no native cancellation command. Component permission flags test rendering/actions, not server authorization.

Thirteen reviewed health/alert/activity/deadlock/onboarding/operations/reports/analytics source-check bundles are replaced with native API/parser and mounted behavior. Health/Activity security constraints and App deadlock/Activity route wiring plus capture-selection copy remain explicitly named lint; the copy assertion is not proof of automatic capture selection. Existing pure model tests remain useful and are retained; this scoped migration does not claim every repository source assertion is behavioral coverage or replace dashboard integration coverage.
