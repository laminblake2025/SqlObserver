## Step 1 cross-target authorization — verified

The vulnerable path was an authenticated target request passing a read-role check
on one target and an unrelated role's union-scope check on another, after which
the repository read the requested target. `AuthorizationContext.RequireAny`
now requires an allowed role on that same target before repository access.
Deadlock, query-performance, operational-health, analytics and alert services use
this helper. The alert policy still permits Auditor and SecurityAdministrator;
those roles do not acquire operational telemetry access.

Overview now narrows inventory to the operational reader grants **before** paging
and loading capability profiles. Explicit unauthorized selections deny before
inventory I/O. Standalone target inventory retains its broader reader policy.
