## Cursor configuration and continuation

The server reads a Base64 signing key from `SqlObserver:Mcp:CursorSigningKey`,
then the legacy `SQLOBSERVER_MCP_CURSOR_KEY` configuration/environment value.
An invalid preferred key disables signing rather than silently selecting a
different key. Keys must decode to 32–4,096 bytes. Startup emits one warning when
the final service registration has no signer; the warning contains no key value.
Explicit signer registrations are preserved whether registered before or after
MCP composition.

Without a signer, a paginated tool returns its first page, keeps `hasMore` truthful,
and omits `nextCursor`. It rejects supplied continuation tokens before querying.
The instance, active-alert, database-health, and file-I/O mappers now expose
`hasMore`, including when continuation cannot be offered.

All paginated time-window tools retain the original effective bounds on later
pages. Existing typed cursors supply their stored bounds. Metric-series and
job-failure cursors carry a small authenticated MCP-only window context, which is
removed before passing the cursor to application services. Caller arguments are
not mutated: the signature remains bound to the original tool and arguments.
Explicit bounds must match the preserved window. Old cursors without saved bounds
are accepted only when both bounds were explicit in the signed request.

One 2,048-character limit now governs cursor input schemas, output schemas,
encoding, and decoding. A full query-performance tie tuple exceeds the old
1,024-character bound and fits the new one. Typed cursor decoding also accepts
the mapper's camel-case enum strings while rejecting integer enum values and
unknown members. Default timestamps are rounded to PostgreSQL microsecond
precision so blocking-history queries satisfy the repository time contract.

## Backup output and schema validation

Backup rows with no known UTC finish time now include `backupAtUtc: null`.
The field remains required and explicitly permits JSON null. This preserves the
distinction between a missing observation and an observation with an unknown
timestamp, without inventing a date or changing other optional-field mappings.

The mapper tests now use JsonSchema.Net 9.4.0 instead of recursive checks that
ignored required fields. This is a test-only dependency. Tests cover unknown
coverage, no backup in the retained history, unknown source time, known UTC time,
and empty snapshots. Negative controls remove a required field, substitute an
incorrect type, and add an unadvertised property. Both existing representative
25-tool mapper checks also use the real validator.

The genuine pre-fix schema run failed all three unknown-timestamp cases and
passed seven controls/representative checks. Evidence:
`artifacts/revamp-mcp-schema/schema-red.trx`.

## Generated HTTP errors

Errors generated by the HTTP boundary use a JSON-RPC 2.0 envelope with a numeric
error code, a safe message, and the existing machine-readable reason under
`error.data.reason`. Request correlation preserves string and signed 64-bit
integer IDs. Missing, malformed, out-of-range, and incompletely read IDs become
JSON null. No exception details are disclosed.

The existing HTTP statuses and audit ownership remain unchanged. A required
audit append is attempted once; failed audit persistence withholds the captured
response. Already-started responses and output-copy failures retain their prior
handling. Successful notifications do not acquire synthetic error replies.

Tests use both direct boundary calls and the official SDK client over ASP.NET
Core TestServer. They distinguish HTTP status, literal wire JSON types, SDK
behavior, and audit attempts/records. The SDK recognizes the corrected oversize
HTTP 200 response as a protocol error; it surfaces HTTP 503 as a transport error
even when the response body is valid, correlated JSON-RPC.

The executable pre-fix HTTP run had 29 failures and three passing controls.
Earlier fixture compile/stream-interception corrections and a later incorrect
SDK-503 expectation are test-harness corrections, not additional product defects.
